# supervised-ml

An introduction to supervised machine learning, focusing on **regression** and **classification**, inspired by Andrew Ng’s Coursera course  
**[Supervised Machine Learning: Regression and Classification](https://www.coursera.org/learn/machine-learning)**.

The full course content (lectures and labs)  is implemented in **MATLAB**, with additional experiments and extensions beyond the original syllabus.

🌐 **Website:** https://anilyesilkaya.github.io/supervised-ml/

## What’s inside

This repository is organized into weekly modules, along with a small set of supporting assets:

- `Week_1/` – Week 1 materials  
- `Week_2/` – Week 2 materials  
- `Week_3/` – Week 3 materials  
- `images/` – Figures and visuals used by the repository and website  
- `index.html` – A simple landing page for browsing the content  

The primary languages used in this repository are **MATLAB** and **HTML**.
